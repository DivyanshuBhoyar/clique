Features:

Communication:
1.  Realtime chat rooms: a. Main room b. topic-wise threads c. a timed thread that auto deletes
2. Reaction with custom emojis
3. Mood based chat rooms

Identity and presence:
1. custom nickname
2. activity status (currently doing)
3. vibe-indicator  for current mood
4. activity streaks visible on profile

Notes:
1. personal notes per member, one for daily journal
2. Shared notes: eg: trip planning, ideas, random lists
3. Friend notes (public): eg: this guy oves me xx

Drops:
Drops feed — a scrollable feed. Each drop card has:
- category tag chip at top-left: 🎵 Song · 🎬 Movie · 📖 Book · 💡 Life hack · 💬 Quote · 🌀 Random
- Dropped by: avatar + nickname + timestamp
- Reaction strip: custom emoji reactions
- Comments count → taps into the comment thread. Each drop can have comments

Memory:
This is the emotional heart of the app. Three sub-sections, accessible via a pill segmented control at the top:
Wall — a masonry/grid layout. Cards can be: a quote, an inside joke entry, or a photo. Each card has a subtle colored tag (quote = amber, joke = pink, photo = default). Long-press to react. Tap opens full detail.
Events/Trips — a vertical timeline. Each event is a card with: cover photo, title, date range, and a "reflections" count. Tapping opens the event detail screen which is like a mini scrapbook — photos grid, links, and a reactions/comment section per item.

Fun
Anonymous confessions within group
Polls
Weekly questions (manual initially, later genrated by AI) with custom UX

Privacy / Closed squads
* Invite-only
* No public profiles
